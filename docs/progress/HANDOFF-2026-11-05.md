## 9. Decisions (ADRs)

- **ADR-042, automatic comps:** suggested, never auto-saved. RentCast comparables are labeled "list price, not a recorded sale".
- **ADR-043, Spanish follow-ups:** a Spanish step version chosen by `contacts.language`. Spanish keywords match the whole message only.
- **ADR-044, Spanish booking page:** the language comes from the visitor. Only a contact the booking itself created is marked Spanish.
- **ADR-045, Spanish newsletters:** two versions, chosen per recipient. CAN-SPAM in both languages.
- **Would reverse:** nothing. Watch "PARA" as an opt-out word (see question 3).

## 10. Known issues / tech debt (ranked)

1. Comp suggestions read up to 2,000 recorded sales and 2,000 saved comps per page view. That's fine now, but they need indexing or a materialized view at scale.
2. Saved comps from other properties have no coordinates, so they rank by ZIP or city only.
3. The owner's own booking-page text (title, intro, location) has one language. A Spanish version would need new settings columns.
4. Today's performance score (85) is the lowest, because it loads the most cards.
5. CI once failed to start the local Supabase stack (port 54324 in use) before any test ran. A re-run passed. If it repeats, add `supabase stop` before `start` in CI.
